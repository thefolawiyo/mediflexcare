# Mediflex: Your Hospital Hub

Design and develop a web-based Hospital Management System (HMS) MVP named Mediflex, that supports all key user roles in a hospital environment. The system should be clean, intuitive, and optimized for speed and reliability.

User roles to include:
• Patients
• Doctors
• Nurses
• Front Desk / Receptionists
• Admin / Hospital Management
• Lab & Pharmacy Staff

Core MVP features:
• Patient registration & profile management
• Appointment scheduling & queue management
• Doctor dashboard for viewing patients, medical history, and visit notes
• Nurse dashboard for vitals, care tasks, and patient monitoring
• Front desk interface for check-in, billing status, and patient flow
• Lab & pharmacy modules for test requests, results, and prescriptions
• Admin panel for staff management, roles, reports, and system settings
• Secure login, role-based access, and audit logs

Design & UX requirements:
• Web app UI with a modern, professional healthcare aesthetic
• Responsive layout for desktop and tablet use
• Clear navigation by role (sidebar + top bar layout)
• Data tables, forms, dashboards, and status indicators
• Accessibility-friendly (large text, clear contrast, simple flows)

MVP goal:
Deliver the smallest usable product that allows a hospital to register patients, manage appointments, document visits, run basic lab/pharmacy workflows, and track operations securely in one system.
